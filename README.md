# ⌂ FindUrHome

**Жильё со всех сайтов в одном окне — и ИИ-помощник, который ищет вместо вас.**

FindUrHome — открытый агрегатор жилья по всему миру. Один запрос уходит сразу на все
подключённые сайты, результаты сводятся к единому формату, цены пересчитываются в вашу валюту,
а один и тот же объект с разных сайтов склеивается в одну карточку, где видно, на каком сайте он дешевле.

- **Два режима:** посуточно / отели и долгосрочная аренда.
- **ИИ-помощник в чате:** опишите, что ищете, своими словами («двушка в Стамбуле на месяц до 1000$,
  чтобы рядом было метро»). Помощник сам составит запрос, запустит поиск по всем сайтам, покажет
  результаты на карте и поможет выбрать.
- **Фильтры:** цена, валюта, комнаты, рейтинг, тип жилья, сортировка, избранное.
- **Карта** с ценами на метках.
- **Новый сайт подключается без кода:** одна запись в `config/sources.yaml`.

## Источники

| Источник | Режим | Ключ | Что даёт |
|---|---|---|---|
| **Rentola** | долгосрочно | не нужен | агрегатор аренды, десятки стран |
| **Craigslist** | оба | не нужен | объявления от владельцев, 700+ регионов (США, Канада, Европа, Азия) |
| **OpenStreetMap** | посуточно | не нужен | все отели и хостелы мира, без цен |
| **Google Hotels** (SerpApi) | посуточно | `SERPAPI_KEY` | метапоиск: цены Booking, Expedia, Agoda, Hotels.com, Trip.com, а также Airbnb и Vrbo |
| **Booking.com** (RapidAPI) | посуточно | `RAPIDAPI_KEY` | живые цены Booking |
| **LiteAPI** | посуточно | `LITEAPI_KEY` | 2+ млн отелей, бесплатный sandbox |
| **Apify-акторы** | любой | `APIFY_TOKEN` | Zillow, Idealista, Rightmove, Avito, Cian, Sahibinden… через конфиг |
| **Любой сайт с JSON-LD** | любой | — | одна строка в `config/sources.yaml` |
| Демо-данные | оба | — | синтетика, чтобы интерфейс работал совсем без сети |

Без единого ключа уже работают Rentola, Craigslist и OpenStreetMap. Чем больше ключей добавите,
тем шире охват.

> Amadeus Self-Service API (раньше популярный бесплатный API отелей) закрыт с 17.07.2026,
> поэтому здесь не используется.

## Быстрый старт

```bash
git clone https://github.com/SergeyKorzikov/FindUrHome.git
cd FindUrHome
pip install -r requirements.txt
cp .env.example .env        # впишите ключи, которые есть (все необязательны)
uvicorn app.main:app --reload
```

Откройте http://localhost:8000.

Через Docker:

```bash
docker build -t findurhome .
docker run -p 8000:8000 --env-file .env findurhome
```

## ИИ-помощник

Провайдер выбирается в `.env`:

| Вариант | Настройка | Цена |
|---|---|---|
| **Claude** (лучше всего ведёт диалог) | `ANTHROPIC_API_KEY=...` | платно, по токенам |
| **OpenAI / OpenRouter / Groq** | `AI_PROVIDER=openai`, `AI_BASE_URL=...`, `AI_API_KEY=...`, `AI_MODEL=...` | зависит от сервиса |
| **Ollama локально** | `AI_PROVIDER=openai`, `AI_BASE_URL=http://localhost:11434/v1`, `AI_MODEL=qwen2.5:14b` | бесплатно, на своём компьютере |
| **Без ключа** | ничего не задавать | простой разбор фраз: город, срок, бюджет, комнаты, даты |

Как это устроено: у модели есть инструмент `search_housing`. Она переводит разговор в
структурированный запрос, вызывает агрегатор (может несколько раз, например чтобы сравнить районы),
получает сжатую сводку результатов и обсуждает её с вами. Найденное одновременно появляется в
списке и на карте, а фильтры на странице подстраиваются под запрос. Помощник видит, что открыто у вас
на странице, и ваше избранное, поэтому можно спросить «какой из этих трёх лучше для работы из дома?».

Ключ хранится только на сервере, в браузер он не передаётся.

## Как подключить новый сайт

**Вариант 1 — без кода (JSON-LD).** Многие сайты недвижимости ради SEO кладут объявления в
`<script type="application/ld+json">`. Проверьте страницу выдачи (Ctrl+U → поиск `ld+json`), затем добавьте:

```yaml
jsonld:
  - id: mysite
    name: Мой сайт
    modes: [long]
    countries: [tr]          # необязательно
    url: "https://example.com/rent/{city_slug}?max={price_max}&page={page}"
    pages: 2
    price_unit: month
```

**Вариант 2 — Apify.** На Apify есть готовые скрейперы почти для любого сайта. Укажите `actor`,
`input` и карту полей `map` (см. пример с Zillow в `config/sources.yaml`).

**Вариант 3 — свой адаптер.** Унаследуйтесь от `Source` в `app/sources/`, реализуйте
`async def search(q, area) -> list[Listing]` и добавьте класс в `BUILTIN` в `app/sources/__init__.py`.

## API

- `GET /api/search?location=Berlin&mode=long&price_max=900&currency=EUR&rooms_min=2`
- `GET /api/sources` — какие источники включены и каких ключей не хватает
- `POST /api/chat` — `{"messages":[{"role":"user","content":"..."}], "context":{...}}`
- `GET /docs` — интерактивная документация (Swagger)

## Устройство

```
app/
  main.py          FastAPI: /api/search, /api/chat, раздача сайта
  ai.py            ИИ-помощник: Claude / OpenAI-совместимые / простой режим
  aggregator.py    параллельный опрос, валюты, дедупликация, фильтры, ранжирование
  geo.py           геокодинг (Nominatim) с поддержкой падежей («в Стамбуле»), курсы валют
  sources/         адаптеры источников
config/sources.yaml  сайты, подключаемые без кода
static/            фронтенд (HTML + JS + Leaflet)
tests/             pytest
```

Каждый источник опрашивается параллельно с таймаутом. Если один сайт упал, остальные результаты
всё равно показываются, а в шапке выдачи видно, какой источник сколько вернул и где была ошибка.
Результаты кэшируются на 30 минут.

## Настройки

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `SOURCE_TIMEOUT` | 45 | таймаут одного источника, с |
| `CACHE_TTL` | 1800 | время жизни кэша, с |
| `MAX_DISTANCE_KM` | 60 | отсекать объявления дальше этого расстояния от центра |
| `SERPAPI_VACATION` | 1 | дополнительно искать Airbnb/Vrbo через Google |
| `DISABLE_DEMO`, `DISABLE_OSM` | — | `1` — выключить источник |

## Честно о сборе данных

Официальные API (SerpApi, RapidAPI, LiteAPI, Apify) — предпочтительный путь. Источники, которые читают
публичные страницы (Rentola, Craigslist, JSON-LD), обращаются к ним редко (кэш, 1–3 страницы на запрос)
и только по прямому запросу пользователя. Перед публичным или коммерческим запуском проверьте условия
использования каждого сайта и при необходимости переключитесь на их официальные API или партнёрские программы.
